# CE SSRU Navbar Motion CSS

Stylesheet สำหรับเพิ่ม UI Motion และ Animation ให้กับ Navbar ของเว็บไซต์สาขาวิชาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยราชภัฏสวนสุนันทา (CE | SSRU)

## การใช้งานผ่าน jsDelivr CDN

```html
<link href="https://cdn.jsdelivr.net/gh/kchayta32/ce-ssru-navbar@main/ce-navbar.css" rel="stylesheet">
```
